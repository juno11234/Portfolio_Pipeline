이슈들

1. 블렌더에서 임포트한 모델 스케일 100되는 버그
Apply Scalings를 All Local로 세팅, FBX Units Scale로 바꿔 수정
파일에 적힌 값을 있는 그대로 정직하게 읽기 vs 유니티가 뵨환해서 Scale 1로 읽기
설정 프리셋으로 만들어 같은 실수 방복 방지

2. 블렌더 모델 임포트 회전 버그
상속구조가 있는 모델은 회전값이 0 인 빈 루트를 자동으로 만들어 회전을 흡수
하지만 상속 구조가 없는 모델은 오브젝트 자신이 루트가 되면서 회전 보정에 문제가 생김
Bake Space Transform기능을 이전에 사용했을 때 (냉장고) 자식의 Transform이 변경 되는문제 때문에 off 했지만 
단일 오브젝트에서는 자식이 없어 해당 문제를 겪을일 없고 오히려 회전을 0으로 보정하는데 필요함

3. 그림자 찢어지는 버그
URP 는 카메라로부터의 거리에 따라 그림자를 여러 단계로 나눠 각기 다른 해상도로 렌더링
그런데 그림자가 이 경계선의 걸쳐저 그림자 렌더링이 둘쭉날쭉해짐 Cascade 수치를 조절하여 해결

4. 프로파일링 및 가비지 최적화
중간에 뾰족한 부분은 DXGI.WaitOnSwapChain으로 작업이 없어 대기중 최적화 대상아님
Profiler로 가비지 원인 TMP인것 추적
TMP Awake, OnEnable은 가끔씩 일회성이나 괜찮지만
SetArraySizes는 런타임에 여러번 호출 가능성
미리 배열 크기를 넓혀 해결

5. 렌더링 디버깅 (그림자 최적화)
Draw Call은 높지만 SetPassCall이 낮아 성능에 지장 없다고 판단
하지만 Cast Shadow가 너무 높음 정적 오브젝트 그림자를 굽기로 결정했으나 그림자가 전부사라지는 문제
튼 셰이더를 구현할때 ShadowMask호환 되지 않게함, 코드 수정하여 적용 그림자 142에서 20 이하로 감소
